Quarantine & Purge

1-Click File Quarantine & Permanent Purge

Jab bhi koi malicious webshell ya dropper file (wp-content/uploads/*.php ya mu-plugins) flag hoti hai:

  • Quarantine Action: File ko turant /var/quarantine/ me move karke chmod 000 kar deta hai (browser ya server se execute hona impossible).
  • Purge Action: Server disk se directly permanently delete karne ka safe option.
  • Auto-Resolve: Dashboard aur database ke active alert records ko instantly RESOLVED mark karta hai.
Privilege Defense

1-Click Rogue Admin Neutralization

Agar koi hacker ya vulnerability se unauthorized user WordPress me administrator privileges gain kar le:

  • Out-of-Band Execution: 1-click se site owner ke Linux user context me command run hoti hai: wp user delete <user> --reassign=1 --yes.
  • Zero Data Loss: User ka saara content master administrator ko safely reassign ho jata hai.
  • Instant Neutralization: Rogue account session instantly terminate ho jata hai bina WP dashboard khole.
Database SRE

Guardian 2.0 runs completely out-of-band at the Linux host level. When a suspicious webshell or backdoor is detected in uploads or mu-plugins, Guardian allows instant 1-click quarantine to /var/quarantine/ with chmod 000, making execution mathematically impossible. If a rogue admin account is injected, Guardian deletes it out-of-band via WP-CLI with automatic content reassignment to the master admin.

Traditional WordPress plugins execute inside PHP, meaning the server still spends CPU and RAM parsing malicious hits. Guardian's Host-Level Threat Shield dynamically injects top-priority drop rules into Linux UFW/iptables (sudo ufw insert 1 deny from <ip> to any). Attack packets are dropped at the kernel network stack before ever reaching Nginx or PHP, keeping your server running at sub-2% CPU overhead.
